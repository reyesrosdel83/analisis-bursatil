# Análisis Bursátil con Python

Proyecto para automatizar el análisis de acciones de tecnología (MSFT, AAPL, NVDA) usando datos reales de Yahoo Finance.

## ¿Qué hace?
- Descarga automática de precios de cierre de los últimos 6 meses
- Limpia los datos con Pandas
- Genera un reporte en Excel con variación diaria y resumen

## Tecnologías
Python, yFinance, Pandas, OpenPyXL, Jupyter Notebook

## Cómo ejecutarlo
pip install -r requirements.txt
jupyter notebook analisis-acciones.ipynb

## Resultado
Genera un archivo `reporte_acciones.xlsx` listo para análisis.

## Qué aprendí
Uso de APIs financieras, manejo de DataFrames, automatización de reportes.
